# デザインディレクション — upper-focus-cycle

対象: 機能は変えず、見た目と情報設計だけを直す。実装は `globals.css` のトークンと `src/components/program-app.tsx` のクラス／レイアウトが主戦場。コンポーネントライブラリの追加、AI-DLC、認証、オンボーディングはしない。

会話言語は日本語。UI 文言も日本語のまま。

---

## 1. Design thesis

これはフィットネススタートアップのランディングではない。一人のトレーニーが、ラックの前で「今日なにを何キロで何セットか」を確認し、終わったらチェックする**鉄の記録帳**である。背景は冷たいグレーではなく酸化した鉄、文字はチョーク、強調は真鍮のプレートのような温かい金属。優先順位（肩・僧帽・胸 → BJJの腕 → デッド → スクワット維持）は色の虹ではなく、タイポと余白と一つの金属色で示す。最初に開いた画面はマニフェストでも解説でもなく、**今週のセッション**である。

**In:** 鉄 / チョーク / 記録  
**Out:** スタートアップ / 虹 / ネオン

---

## 2. 現状 UI の問題

- **ヘッダーが本体を押し下げている。** `h1` が `text-3xl`〜`4xl`、説明文、Excel / CSV / Sheets / ZIP / 固定Excel の5アクション、1RM 5欄が常時展開。ジムのスマホでは「今日の種目」までスクロールが長い。
- **アクセントが弱い・散らばっている。** トークンはほぼ無彩色の oklch グレー。真の accent は Tailwind の `amber-500` を eyebrow・選択週・メインラベル・ダンベルアイコン・ボリュームバーに薄く塗っただけ。ブランド色になっていない。
- **筋群チップが虹。** `MUSCLE_TONE` が rose / amber / orange / sky / violet / teal / stone。優先部位（胸・肩・僧帽）と維持部位（四頭）が同じ視覚重量。タグクラウドに見える。
- **フェーズも虹。** MAV超=emerald、ビルド=blue、MRV=red、ディロード=zinc。ボリューム判定の `FLAG_TONE` も同様。警告（MRV）と成功（完了の emerald ring）が別系統で、ログの意味が色の種類で増えていく。
- **種目行の数字が小さい。** ジムで必要な `sets × reps @ weight` が `text-sm`。種目名とメモとチップが同等。完了は `opacity-55` で潰すだけで、「 chalk で消した」感じがない。
- **「今日」がない。** 週チップ → 月〜金5枚が常に同等。土日カードも同じ Card サイズ。スマホでは今日のセッションへ辿り着く導線がない。
- **書き出しが全部ボタン。** `Button` default が dark ではほぼ白（`--primary: oklch(0.922 0 0)`）。Excel が README 上の主アクションなのに、CSV や ZIP と同じ帯に並び、ヘッダー右がツールバー化している。
- **カードが SaaS。** `--radius: 0.625rem`、`rounded-xl`、`ring-foreground/10`、装飾の `Dumbbell`。ガレージのノートではなく shadcn のダッシュボード。BJJ 注記だけ `text-sky-300` で、また色が増える。

## 3. 情報設計 / レイアウト

画面は今どおり **1ページ・4タブ**。ルートもタブ ID（`week` / `sheet` / `volume` / `guide`）も変えない。変えるのは「何が最初に目に入るか」と「何を折るか」。

### 最初に開いたとき（primary）

1. **コンパクトな見出し**（1行の製品名 + 1行の状態）
2. **週レール**（1–16。選択週・ブロック・フェーズがすぐ読める）
3. **タブ**（既定は「今週のメニュー」）
4. **セッションカード**（Day A–E。スマホでは今日の曜日を先頭付近へ）

これが above-the-fold。ウォームアップ一文（`MAIN_WARMUP`）はセッション群の直上に `text-xs text-muted-foreground` で置く。消さない。

### 最初は二次（secondary）

- 1RM / 体重入力
- 書き出し5種
- 「初期値に戻す」
- 土・日の休養カード
- 今週のセット数（VolumeStrip）
- スプレッドシート / ボリューム表 / 解説

二次は消さない。**折る・下げる・視覚重量を落とす。**

### ヘッダー

**デスクトップ（≥768px）**

```
[ 上半身フォーカス 16週 ]                    [ Excelをダウンロード  ] [ その他 ▾ ]
[ ブロック2 筋力×肥大 · 週7 · MRV週 ]         または CSV / Sheets / ZIP / 固定Excel を ghost で横並び
```

- 見出しは短く。現行コピー「上半身を厚くする。デッドを伸ばす。」は残してよいが **`text-xl`〜`text-2xl`、`font-bold`、1〜2行まで**。英語 eyebrow（`16-week cycle · 74kg · BJJ` + tracking）は廃止。代わりに日本語の1行メタ: `16週 · 器具はバーのみ · 土休・日BJJ`。
- 長い説明段落はヘッダーから外す。中身は「解説」タブと README にある。ヘッダーに残すなら **1行クランプ**。
- 1RM 5欄はヘッダー内の **1行コンパクト**（ラベル短縮: ベンチ / スクワット / デッド / OHP / 体重）。「OHPは推定…」の注記は入力行の下に `text-xs`。リセットは注記横の ghost。

**スマホ（ジム）**

- 見出しは1行（製品名のみでも可）。説明文は出さない。
- 1RM と書き出しは `<details>` 相当の開示。「1RMと書き出し」で閉じる。中を開くまでセッションを見せる。
- 開示内の主ボタンは Excel のみ。CSV / Sheets / ZIP / 固定Excel はテキストリンクまたは ghost を縦に積む。

### 週レール

- 16個を **4ブロックにグルーピング**（1–4 / 5–8 / 9–12 / 13–16）。グループ間に細い鉄の隙間。グループ上または下にブロック名を `text-[10px] text-muted-foreground` で。
- 選択中は真鍮（`--primary`）。MRV週（未選択）は錆のリングのみ。ディロード週は文字を一段落とす（opacity ではなく `text-muted-foreground`）。
- レール右または直下に、選択週の要約を **一文**: `ブロック2 筋力×肥大 · 12種目 · 3/12 完了`。現行の Badge 2個 + 長い `block.focus` は、focus を `title` かレール下の1行に移し、Badge はフェーズ1つだけ。

### セッションカード（今週タブ）

- **主コンテンツ。** Day A–E が画面の8割の理由。
- カードヘッダー: `火 · Day B` をタイトル、`デッド＋背中・僧帽` をサブ。 Dumbbell アイコンは外す。
- スマホ: **1列。今日の曜日のカードを視覚的に「現在」**（左に 2px の真鍮バー、またはヘッダー背景を一段上げる）。月〜金以外（土日）は今日でもセッションが無いので、休養カードを先に出し、その下に週のリフトを通常順で置く。
- デスクトップ: 現行どおり `lg:grid-cols-2`。今日カードだけ左ボーダー。
- 全日完了: 緑の ring ではなく、ヘッダー右に `完了` を Geist Mono で小さく。カード全体は一段落ち着いた surface。
- 土日: 破線のまま。高さはリフトカードの半分でよい。`bg-muted/20` を維持しつつ、虹を足さない。

### スプレッドシートタブ

- 説明文は1行。トグル「今週だけ表示 / 全16週を表示」は右。現行ロジック維持。
- 表が主。完了チェック列は残す（localStorage と同じ `done`）。

### ボリュームタブ

- 16週 × 8部位の表が主。行クリックで週選択（現行）。選択行は amber ではなく **surface 一段上げ + 左に真鍮バー**。
- 優先部位（胸・肩・僧帽）の列は見出しを `font-medium`。他列は muted。

### 解説タブ

- 読ませるテキスト。カードの rim を減らす。`SCIENCE_SECTIONS` は見出し+本文のスタック。種目ガイドは右カラム（デスクトップ）または下（スマホ）。ブロック一覧は短い定義リスト。
- ここだけ本文の行長を `max-w-prose`。数字や%は本文中でも Noto。表や処方数字は出さない（それらは他タブ）。

## 4. カラーシステム（oklch）

`html.dark` 固定のまま。`:root` のライト値は触らなくてよい（使っていない）。`.dark` と、必要なら `@theme inline` に意味トークンを足す。

狙い: **鉄（背景）・チョーク（文字）・温かい金属（選択と主アクション）・錆（MRVだけ）。** 紫の SaaS プライマリ禁止。ネオン禁止。現行 `--sidebar-primary` の青紫（`oklch(0.488 0.243 264)`）は使わない。

実装側で `MUSCLE_TONE` / `PHASE_TONE` / `FLAG_TONE` の Tailwind palette クラス（`rose-500` 等）をやめ、これらの変数を参照する。

## 5. タイポグラフィ

**本文・UI ラベル・種目名は Noto Sans JP のみ。** `layout.tsx` の 400 / 500 / 700 を維持。800 以上を足さない。

| 役割 | フォント | サイズ | ウェイト | 行 |
| --- | --- | --- | --- | --- |
| h1（ヘッダー） | Noto | `1.25rem` スマホ / `1.5rem` sm以上 | 700 | `leading-tight`。`text-3xl`/`4xl` は使わない |
| セッションタイトル | Noto | `1.0625rem`（≈17px） | 500 | `Day B · 火` |
| 種目名 | Noto | `0.9375rem` | 500 | メインは名前の後に小さく `メイン`（英語 MAIN はやめる） |

| ラベル・チップ・注記 | Noto | `0.6875–0.75rem` | 400–500 | tracking は通常。`tracking-[0.22em]` の英字 uppercase はやめる |

## 6. コンポーネントレシピ

既存の shadcn（Button, Card, Badge, Tabs, Table, Checkbox, Input, Label）を **捨てずにトークンと className で再調律**する。新しい UI パッケージを入れない。

### 週チップ

- サイズ: `h-9 w-9`（スマホのタップ）。`min-w-9` のまま。
- 未選択: `bg-card text-muted-foreground`、ring は `--border`。
- 選択: `bg-primary text-primary-foreground`、ring も primary。**黒文字 on amber-500 はやめる**（primary-foreground の鉄色を使う）。
- MRV・未選択: `ring` を `--mrv`。中塗りは変えない。
- ディロード・未選択: 文字 muted。ring 通常。`opacity-70` はやめる（タップしにくく、コントラストが落ちる）。
- ホバー: 文字を foreground。scale / shadow なし。
- ブロック区切り: 4つずつ `inline-flex gap-1`、グループ間 `gap-3`。

### セッションカード

- `Card` の ring を `ring-border` 相当の溶接線。`ring-emerald-500/30` は使わない。
- ヘッダーは `border-b border-border`、padding は現行 `--card-spacing` でよい。
- 今日: `border-l-2 border-l-primary`（カード左）。
- 種目リストは `divide-y divide-border`。行パディング `py-3 px-4`。スマホは縦方向をもう 4px 足して誤タップを減らす。

### 種目行（チェック + 名前 + 処方）

レイアウト（左→右）:

```
[ □ 44pxヒット ]  [ 種目名 ＋ メイン ]
                  [ 4 × 8 @ 100kg     72% / RPE8 ]
                  [ 胸 肩 ]  休憩 2分
                  [ メモ。BJJ: … ]
```

- Checkbox は見た目 `size-4` のままでよいが、ヒット領域は現行 `after:-inset-*` を活かし、**少なくとも 44×44 相当**。チェック色は `--done`（primary の真鍮でも可。完了=記録なので done の方が意味が明快）。
- 処方行は右寄せせず、種目名の**直下左揃え**（ジムで縦に目が落ちる）。現行の `justify-between` はデスクトップで数字が右端に飛び、視線が往復する。
- `displayWeight` が主。`2.5kg` 丸めの結果を Mono で。`percent1RM` は括弧やスラッシュで従属。
- チップは優先部位だけ出す、はデータ変更になるので **出している筋群は全部出す**。見た目だけ上記の低彩度にする。`rounded-full` はチップのみ可。
- メモは1行〜2行。切らない（処方の一部）。

### ボリュームバー（VolumeStrip）

- 高さ `h-1.5`（現行 `h-2` から少し細く。ログの補助）。
- トラック `bg-muted`。塗りは flag に従う（全部 amber 禁止）。
- ラベル左に部位名（Noto）、右に `12 · MAV超`（Mono + FLAG_JA）。
- 今週タブの下に置くのは維持。スマホではアコーディオン「今週のセット数」にして、既定は閉じてよい（セッションが primary のため）。デスクトップは開いたまま。

### テーブル（Sheet / Volume）

- ヘッダー: `text-xs text-muted-foreground`、`font-medium`、背景 `bg-card` またはわずかな muted。sticky header はシートが長いときのみ（`thead` sticky top。週レールの下に来る場合は `top` をレール高さに合わせない。実装コストが高ければ横スクロールのみでよい）。
- セル: 数値は Mono、Day / 種目 / メモは Noto。
- 完了行: opacity 50% ではなく muted 文字。チェックは残す。
- ホバー: `bg-accent`。ボリューム表の選択行は `bg-muted` + 左ボーダー primary。
- 横スクロールはスマホ必須。最初の「チェック + Day + 種目」が読める幅を優先。重量〜メモはスクロール先。

### 書き出しアクション

優先順位（視覚重量）:

1. **Excelをダウンロード** — `Button` variant default（真鍮 primary）。ヘッダーに常時1つ。README の主経路。
2. **Sheetsに貼る** — outline。コピー済みはチェックアイコン + 文言変更（現行ロジック）。
3. CSV / ソースZIP / 固定Excel — ghost またはテキストリンク。デスクトップは Excel の右に小さく。スマホは開示内。

「初期値に戻す」は destructive にしない（データ全消しだが、見た目の警報色は MRV 専用）。ghost + 確認なしの現行挙動を維持するなら、ラベルをMutedのまま。

### タブ

- `TabsList variant="line"` 維持。アクティブ下線を **foreground 白チョークではなく primary 真鍮 2px**。
- ラベル: 今週のメニュー / スプレッドシート / ボリューム / 解説。短くしない（意味が落ちる）。
- スマホ: 横スクロール可、折り返さない。`w-full` で4等分すると文字が潰れるので、`justify-start` + トリガーは内容幅。

### 入力

- 1RM は `h-9` まで上げてよい（ジムではなく家で触る想定だが、誤タップ防止）。`tabular-nums`。
- focus ring は真鍮。赤リングは validation がないので使わない。

## 7. モーション

ほぼ無し。フィットネスアプリのパルスやタブフェードは禁止。`tw-animate-css` の入場アニメをコンポーネントに足さない。

**許可（150ms 以下、easing は default）:**

- 週チップ・タブ・ボタンの `transition-colors`
- チェックボックスの塗り
- Sheets コピー済みのアイコン差し替え（タイマー 1600ms は現行どおり。fade は不要）

**禁止:**

- タブパネルの fade / slide
- カードの hover 持ち上げ、scale、shadow アニメ
- 完了時のストライプや confetti
- ボリュームバーの width transition（初期描画でバーが伸びるのはノイズ。つけるなら 100ms まで）

`prefers-reduced-motion: reduce` では上記の colors 以外を `transition: none`。

## 8. レスポンシブ

このアプリの本番は **ジムの片手スマホ**。デスクトップは家でシートとボリュームを見る副画面。

### スマホ（〜767px）

- ヘッダーは短く。1RM+書き出しは折りたたみ。
- **sticky:** 週レール + タブ。`top-0`、`bg-background/95`、`border-b`。スクロールしても週とタブが残る。`backdrop-blur` は薄くてよい（過度なガラス禁止）。
- セッションは1列。今日カードへは sticky の下からすぐ。
- 種目行は折り返し可。処方数字は折り返さず `whitespace-nowrap`。
- 土日カードは折りたたみにしない（短いのでそのまま）。
- VolumeStrip は折りたたみ、既定クローズ。
- シート / ボリューム表は横スクロール。ピンチズームを殺さない（`user-scalable=no` を足さない）。
- タップ対象は 36px 以上（週チップ 36、チェックヒット 44）。

### デスクトップ（768px〜）

- 週レールは sticky しなくてよい（ヘッダーが短いので）。して害はない。
- セッション `lg:grid-cols-2`。
- 1RM は5列グリッド維持可。書き出しは右上。
- 解説は `lg:grid-cols-2` 維持。
- `max-w-7xl` 維持。本文を全幅に広げない。

### 共通

- `print:hidden` は現行どおり書き出し・入力・週チップ・タブに残す。
- 横向きスマホは1列のままでよい（2列にすると種目が潰れる）。

## 9. このコードベース向け実装メモ

- **トークンは `src/app/globals.css` の `.dark`（と必要なら `@theme inline`）だけ変える。** ライト `:root` は放置可。`layout.tsx` の `className="… dark …"` と Noto / Geist Mono の読み込みは維持。
- **見た目のクラスはほぼ `src/components/program-app.tsx`。** `MUSCLE_TONE` / `PHASE_TONE` / `FLAG_TONE` をトークン参照に差し替える。ヘッダー構造、週レールの4分割、種目行のスタック、書き出しの視覚階層、スマホの `<details>` はここ。
- **既存 shadcn を残す。** `src/components/ui/*` は、どうしても ring や radius がトークンに追従しないときだけ最小限。Button の variant 追加や新しいライブラリ（Radix 追加、icon pack 追加、framer-motion）はしない。lucide の Dumbbell は削除してよい。他アイコン（Download 等）は残す。
- **機能・データ・キーを変えない。** `localStorage` キーは `iron-cycle-v2`。`rms` と `done` の形を変えない。`buildProgram` / `weeklyVolumes` / export 関数 / `withBase` のリンクは維持。タブ4つ、週1–16、チェック、コピー済みフィードバック、全週/今週トグル、初期値リセット、固定 xlsx / zip の `href` を残す。
- **今日の強調はクライアントの `new Date()` で曜日を見るだけでよい。** 保存しない。週の状態はこれまで通りユーザーがチップで選ぶ（自動で週を進めない）。
- **文言:** シートの `MAIN` を `メイン` に揃えてよい（表示だけ）。説明文の削除はヘッダーからタブへ移すだけで、情報を捨てない。
- **静的 export のまま。** フォントの weight 追加は必要なら `layout.tsx` の Geist Mono に `weight: ["400", "500"]` を足してよい。それ以上の依存追加はしない。
- **コミットしない。AI-DLC を入れない。**
